# Changelog

## 1.0.1 — 2026-08-24

- Fixed periodic slide-list oscillation caused by competing top-gap and next-slide positioning rules.
- Slide positioning now calculates one deterministic resting position per update.

## 1.0.0 — 2026-08-24

First public release.

- Portrait-first Service and Slides views.
- Sticky header and footer.
- Service-item and slide selection.
- Blank / Show controls.
- Previous / next service-item navigation.
- Optional automatic switch to Slides after selecting a service item.
- Current-slide highlighting and automatic scroll return.
- One-second manual-browse grace period.
- `-- END --` marker after the final slide.
- Font sizes from 85% to 145%, default 115%.
- Enlarged image previews.
- Settings/help panel.
- Browser reload control.
- ES5-style JavaScript for older Safari/WebKit compatibility.
