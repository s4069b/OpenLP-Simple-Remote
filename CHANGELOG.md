# Changelog

## 1.2 — 2026-08-31

- Finalised the Settings/Help visual language and aligned all Help controls, fonts, weights, colours and spacing.
- Added separate, consistently styled Theme and Mixer nerd notes.
- Finalised the iOS-style Settings icon and matching Refresh/Help icons.
- Finalised the optional offline Soundcraft Ui12/Ui16 recorder control, including multiple mixers, Change Mixer cycling, state indication and three-second stop confirmation.
- Added editable default mixers in `stage.html`.
- Improved slide-selection reliability by serialising slide commands and retaining the latest tap rather than dropping quick selections.
- Preserved older Safari/iOS compatibility and the portrait-first remote layout.

## 1.1 — 2026-08

- Added theme customisation and current-slide colour/border controls.
- Improved line-break preservation, slide scrolling, old-Safari compatibility and landscape presentation.
- Introduced the optional Soundcraft recorder integration.

## 1.0 — 2026-08-24

- First public release.
